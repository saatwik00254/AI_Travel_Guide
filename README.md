# 🌍 AI Travel Guide

An AI-powered travel guide that generates personalized audio guides for tourist destinations.

Users can search for any tourist destination, view its image, and generate an AI-powered audio guide in multiple languages and voices.

## 🚀 Live Demo

[AI Travel Guide](https://ai-travel-guide-frontend-282x.onrender.com)

## 📂 GitHub Repository

https://github.com/saatwik00254/AI_Travel_Guide

## ✨ Features

- 🔎 Search for any tourist destination
- 🖼️ Dynamic destination images using Wikipedia
- 🤖 AI-generated travel information using Google Gemini
- 🎧 AI-generated audio guides using Murf AI
- 🌐 Multiple language support
- 🗣️ Male and female voice options
- 📖 Summary and detailed guide options
- 📱 Responsive user interface
- ☁️ Deployed using Render
